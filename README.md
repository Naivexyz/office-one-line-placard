A program that writes a single one-line museum placard for an ordinary office object, treated as an ancient artifact, for make.fun's "Office Artifacts: The One-Line Placard Contest" bounty ($2 in USDC). A dry-witted curator judge compares placards two at a time and picks the more inventive and funnier one.

The placard:

> Stapler, c. 1987, steel. Bound 4,112 contracts in the Rite of the Signature; its jam, on the third Tuesday, was read as an omen.

## Run it

```sh
node main.ts
```

It writes the placard to `/output/entry.txt` (UTF-8, one line, 128 characters).
